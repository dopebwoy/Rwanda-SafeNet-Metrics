Enumerator help

How this prototype works

Your assignment is stored locally. Each household gets a unique prototype code and inherits the assigned Province → District → Sector → Cell → Village hierarchy.

GPS can be captured from the device. Green markers represent saved household locations. The coverage circle is only a prototype visualization; a production version should use official village boundary geometry from an authorized source.

Important: this prototype is not an official Rwanda government system. Do not put real National IDs, phone numbers or other sensitive information into a public demo.
